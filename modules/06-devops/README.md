# Module 6: DevOps and Automation

## What this module covers

- Azure Repos for version control
- Azure Pipelines for CI/CD
- Infrastructure as Code (Terraform, ARM templates)
- Release management and deployment strategies
- Azure Monitor and diagnostic logging

## Key concepts

| Concept | Purpose |
|---|---|
| Pipeline | Automated build, test, and deploy workflows |
| Infrastructure as Code | Declarative resource definitions |
| Continuous Integration | Automated testing on every commit |
| Continuous Deployment | Automated production deployments |
| Monitoring | Observability and alerting for applications |

## Hands-on topics

- Setting up Git repositories in Azure Repos
- Building CI/CD pipelines for applications
- Writing Terraform modules for infrastructure
- Multi-stage deployments with approval gates
- Monitoring applications with Azure Monitor
