# Module 7: Security and Compliance

## What this module covers

- Identity and access management (Azure AD/Entra ID)
- Role-Based Access Control (RBAC)
- Encryption at rest and in transit
- Azure Policy for governance
- Security Center and compliance monitoring
- Data protection and audit logging

## Key concepts

| Concept | Importance |
|---|---|
| Entra ID | Centralized identity platform |
| RBAC | Least privilege access control |
| Encryption | Data protection in storage and transit |
| Policy | Organizational compliance and guardrails |
| Audit Logging | Compliance and forensics |

## Hands-on topics

- Setting up Entra ID for user authentication
- Configuring RBAC roles and assignments
- Implementing encryption for data protection
- Creating Azure Policies for compliance
- Monitoring security events and alerts
