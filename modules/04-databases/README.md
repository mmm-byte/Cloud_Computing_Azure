# Module 4: Database Services

## What this module covers

- Azure SQL Database: managed relational database
- Cosmos DB: globally distributed NoSQL database
- Database migration patterns
- Read replicas and geo-replication
- Backup and disaster recovery

## Key concepts

| Concept | Details |
|---|---|
| SQL Database | Managed PostgreSQL, MySQL, or SQL Server |
| Cosmos DB | Multi-model database with global distribution |
| Replication | Primary-secondary, geo-replication patterns |
| Backup | Automatic backups, point-in-time restore |
| Migration | Data Migration Assistant, offline/online options |

## Hands-on topics

- Provisioning SQL Database instances
- Configuring read replicas and failover
- Cosmos DB collections and partitioning
- Data migration from on-premises or other clouds
- Implementing backup strategies
