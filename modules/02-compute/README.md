# Module 2: Compute Services

## What this module covers

- Virtual machines: creation, sizing, and management
- Virtual machine scale sets for auto-scaling
- App Service for web and mobile applications
- Container Instances and Azure Container Registry
- Managed Kubernetes (AKS)

## Key concepts

| Concept | Use case |
|---|---|
| Virtual Machine | Full OS control, lift-and-shift migrations |
| Scale Set | Auto-scaling VMs based on demand |
| App Service | Managed platform for web apps, APIs, mobile backends |
| Container Instance | Serverless containers without orchestration overhead |
| AKS | Kubernetes cluster management with Azure integration |

## Hands-on topics

- Creating and configuring virtual machines
- Setting up scale sets with custom metrics
- Deploying web applications to App Service
- Publishing Docker images to Azure Container Registry
- Container deployment and management

## Where this connects to my work

Compute services form the core of enterprise applications. Labs demonstrate scaling patterns, deployment automation, and infrastructure provisioning.
