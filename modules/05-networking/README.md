# Module 5: Networking

## What this module covers

- Virtual Networks (VNets) and subnets
- Network Security Groups (NSGs)
- Load balancers and Application Gateway
- VPN Gateway and ExpressRoute for hybrid connectivity
- DNS and Traffic Manager
- Private endpoints and service endpoints

## Key concepts

| Concept | Function |
|---|---|
| VNet | Isolated network within Azure cloud |
| NSG | Stateful firewall rules for subnets and NICs |
| Load Balancer | Layer 4 load balancing for VMs |
| Application Gateway | Layer 7 load balancing and WAF |
| VPN / ExpressRoute | Site-to-site and on-premises connectivity |

## Hands-on topics

- Designing and implementing VNets
- Configuring NSGs and inbound/outbound rules
- Setting up load balancing and traffic distribution
- Implementing VPN for hybrid connectivity
- DNS and routing configuration
