# Module 1: Azure Fundamentals

## What this module covers

- Azure hierarchy: subscriptions, resource groups, regions
- Resource management and organization
- Cost management and budgeting
- Azure Portal and CLI basics
- Resource tagging and governance

## Key concepts

| Concept | Description |
|---|---|
| Subscription | Billing boundary and authorization scope |
| Resource Group | Logical container for related resources |
| Region | Geographic location where resources are deployed |
| Resource | Individual Azure service instance (VM, storage account, etc.) |
| Tags | Key-value pairs for organization and cost tracking |
| RBAC | Role-Based Access Control for permission management |

## Hands-on topics

- Creating and managing resource groups
- Organizing resources with tags and naming conventions
- Viewing and understanding Azure cost analysis
- Setting up budget alerts
- Working with Azure CLI for resource creation and management

## Where this connects to my work

Understanding Azure fundamentals is the foundation for all other services. Proper resource organization, cost tracking, and access control are essential practices demonstrated in all labs and projects.
