# Module 3: Storage Services

## What this module covers

- Blob Storage for unstructured data
- Azure File Shares for SMB/NFS access
- Managed Disks for VM storage
- Storage account types and redundancy options
- Backup and disaster recovery

## Key concepts

| Concept | Purpose |
|---|---|
| Blob Storage | Scalable object storage for any data type |
| File Shares | Network file system compatible storage |
| Managed Disk | Persistent storage for virtual machines |
| Redundancy | LRS, ZRS, GRS, RA-GRS options |
| Lifecycle Management | Automatic data tiering and cleanup |

## Hands-on topics

- Creating and configuring storage accounts
- Implementing blob lifecycle policies
- Configuring managed disks for VMs
- Setting up file shares for application data
- Backup and recovery procedures
