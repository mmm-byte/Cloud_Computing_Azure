## Objective

Understand Azure hierarchy, organize resources, and implement governance through tagging and RBAC.

## Exercises completed

### Resource Organization

| Exercise | Task | Objective |
|---|---|---|
| 1.1 | Create resource groups | Logical organization of resources |
| 1.2 | Implement tagging strategy | Cost tracking and resource identification |
| 1.3 | Configure RBAC roles | Implement least privilege access |
| 1.4 | Set up budget alerts | Monitor and control spending |

## Key points

- Resource groups serve as boundaries for billing and access control
- Tags enable cost allocation and resource discovery
- RBAC provides fine-grained permission management
- Azure CLI enables infrastructure automation
